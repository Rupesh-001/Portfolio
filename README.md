# Rupesh Varma — React Portfolio

Converted from the original HTML, CSS and JavaScript portfolio to React + Vite. Existing sections, project links, project screenshots, resume, responsive styling, theme toggle, email copy action and contact form behavior are retained.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## Production build

Run `npm run build`; the deployable site is created in `dist/`.
